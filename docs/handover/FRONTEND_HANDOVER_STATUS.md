## Known Limitations

- The public page is static and read-only. It does not write ledger events.
- The graph intentionally uses only the 18 pilot rows, not the full corpus.
- The dashboard depends on regenerated JSON after future DB or ledger changes.
- Layer tags are normalized for display from the current pilot/disposition data; future backend tables should eventually store complete canonical layer tags for every row.
- Export buttons operate in the browser from the loaded static state; canonical regeneration remains `scripts/export_frontend_data.py`.
