# KNOWLEDGE PRISM PROJECT BRIEF

## One-line description

KNOWLEDGE PRISM converts a dispersed scholarly archive into an auditable research ontology for geopolitical knowledge structures in International Relations.

## Project object

The object is not simply a library. The object is a corpus-mediated knowledge system: a structured archive in which texts, folders, metadata, concepts, regions, theories, and methods are progressively transformed into a verified ontology.

## Empirical core

- Afghanistan
- Central Asia
- South Asia
- Eurasian connectivity
- China/BRI/CPEC
- Russia/energy corridors
- Taliban and regional security

## Methodological core

- International Relations theory
- Regional Security Complex Theory
- systems theory
- semiotics
- grounded theory
- social-network analysis
- AI-assisted ontology-building

## Intended final communicability

The project should be explainable to three audiences:

1. **Academic audience:** as a method for corpus-based knowledge-structure mapping in IR.
2. **Technical audience:** as a reproducible data/ontology pipeline.
3. **Pedagogic audience:** as a classroom protocol for turning archives into researchable domains.
